One line, at most 200 characters, roasting a smart fridge — its firmware update turned the ice maker into a subscription.

## Run

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (no trailing newline), validated against the gate: UTF-8, 1–200 characters, not only whitespace.

## Entry

> My smart fridge updated its firmware overnight; now the ice maker gives me one cube a day — the rest is a premium feature.
